# Secret Santa

A single static page for Secret Santa draws, hosted on GitHub Pages: https://yllkryeziu.github.io/secret-santa/

1. Enter the names, one per line, and press **Generate**.
2. Each person gets a card. Tap a card to flip it and see who that person is buying for.

Everything runs in the browser. Nothing is stored or sent anywhere. There's a light/dark toggle in the top right.
