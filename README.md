# Secret Santa

A single static page for Secret Santa draws, hosted on GitHub Pages: https://yllkryeziu.github.io/secret-santa/

1. Enter the names, one per line, and press **Generate**.
2. Send each person their own link. Opening a link shows only that person's match.

Everything runs in the browser. Nothing is stored or sent anywhere. Each person's match is stored in their link's `#` part, base64-encoded so nobody can read it at a glance. It is not encrypted.
